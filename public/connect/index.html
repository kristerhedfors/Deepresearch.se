Connect an MCP client

← Back to the app

DeepResearch.Se/rver is also an MCP server. Add it to Claude or ChatGPT — on a phone or anywhere else — and your assistant gets the same deep-research run the chat does: it plans search angles, searches the web, audits its own coverage for gaps, and synthesizes an answer built only from the sources it found, with citations. Claude Code, Cursor and other terminal clients work too; that is section 2.

1. On a phone, or anywhere — add it as a connector

This is the way in for most people, and the only one that works on a phone: you hand Claude or ChatGPT a single URL, they send you here to sign in and approve, and no key is ever created or pasted. If that is what you came for, you are done after this section.

Add to Claude →

That opens Claude's add-connector dialog with the name and URL already filled in. It only prefills: Claude tells you the values came from an external link, and nothing is added until you confirm. If you are signed out you will sign in first and land back on the dialog.

Or paste the URL yourself:

https://mcp.deepresearch.se

Claude — by hand, at claude.ai/customize/connectors

It is under Customize, not Settings — Anthropic moved it there in February 2026, which is why "Settings → Connectors" finds nothing.

  1. Open claude.ai/customize/connectors (left sidebar: Customize → Connectors).
  2. + → Add custom connector.
  3. Paste the URL above. Leave Advanced settings alone — this server needs no client ID or secret.
  4. Approve on the consent screen this site shows you.

On a Team or Enterprise plan only an Owner can add it, at claude.ai/admin-settings/connectors → Add → hover Custom → Web. Everyone else then connects to it individually. On Free, Pro and Max you add it yourself; Free is capped at one custom connector.

The phone: add it on web or desktop, and it is there the next time you open Claude on iOS or Android — Anthropic's own words are that "installing connectors on mobile is currently in beta" and that desktop and web "remain the primary path". So the app can use it; add it from a browser.

ChatGPT — turn on Developer mode first

ChatGPT renamed this twice: Connectors → apps → Plugins. And a self-hosted MCP server needs Developer mode, which is not in the Connectors menu at all.

  1. Settings → Security and login → turn on Developer mode.
  2. Go to chatgpt.com/plugins → the + button.
  3. Give it a name and description, and for the URL use https://mcp.deepresearch.se/mcp — OpenAI's setup expects the /mcp path, unlike Claude.
  4. Create, then review the tools it discovered.
  5. In a chat: the + menu → Developer mode → pick it.

Requirements worth knowing before you start: Developer mode is web only and available on Plus, Pro, Business, Enterprise and Education — not Free. On Business/Enterprise a workspace admin may have to allow it first.

ChatGPT plugins do not reach the phone app. OpenAI's current documentation states plainly that plugins "aren't available in Chat, the IDE extension, or mobile". So unlike Claude, adding this on the web does not make it appear on your phone. If mobile is what you want, Claude is the one that does it today.

Either way you land on a consent screen on this site naming exactly what you are granting — which tools, whose quota, and that the questions are logged — before anything connects. Approving creates a credential for that one connection, so removing the connector in Claude or ChatGPT ends it without touching your other clients.

Newly built, and you may be the first through it. The flow passes its own tests, but nobody has yet completed it from a real connector dialog. If it fails, the terminal path below still works from a laptop. Two things are known-uncertain on ChatGPT's side: whether it accepts our transport (we serve Streamable HTTP; some of OpenAI's pages describe SSE), and whether its connectors reach the phone app at all. ChatGPT also refuses any server without tools named search and fetch — both ship switched on, so leave them on if you want ChatGPT to connect.

2. In a terminal — Claude Code, Cursor, agent SDKs

Only for clients configured from a command line or a config file. If you came here to connect a phone, section 1 was all of it — this is a different route to the same server.

Mint a key

Sign in at deepresearch.se, open Settings (the gear icon) → MCP server → Mint key.

The key is shown once. It authorizes the MCP endpoint and nothing else — it is not a login, and it cannot read your chats, projects, files, history or account. Minting again replaces it; Revoke kills it on the next call.

Add the server

Claude Code, one line — paste your key where the placeholder is:

claude mcp add --transport http deepresearch https://mcp.deepresearch.se --header "Authorization: Bearer YOUR_KEY"

Settings → MCP server has the same line with your key already spliced in. Check it took:

claude mcp list

Other clients

Anything that reads an mcpServers block (Cursor, Claude Desktop, most agent SDKs):

{
  "mcpServers": {
    "deepresearch": {
      "type": "http",
      "url": "https://mcp.deepresearch.se",
      "headers": { "Authorization": "Bearer YOUR_KEY" }
    }
  }
}

Transport is Streamable HTTP (JSON-RPC 2.0 over a single POST). The URL is the bare origin — that host serves nothing but this server, so there is no path to get wrong. If your client insists on one, https://mcp.deepresearch.se/mcp answers identically.

3. Choose what it may reach

Settings → MCP server is also where you decide what a connected agent sees. Every tool has a switch; a tool switched off vanishes from the client's tool list and is refused if the client calls it anyway.

ToolWhat it does
deep_research Runs the full pipeline and returns a cited answer. This is the one that spends — each call draws on your research quota.
literature_search
literature_similar		 Search the hosted arXiv and PubMed indexes by meaning and get back structured paper records — up to six angles at once, both corpora, in a single call. literature_similar does the same from a paper you already have, for a related-work sweep. Both draw on your research quota, but far more cheaply than deep_research: they retrieve, they don't write an answer.
literature_fetch
literature_corpora		 Resolve exact papers by arXiv id or PMID — how an agent follows a citation — and ask what the two corpora actually hold: live vector counts, coverage windows, stored fields. Neither spends anything.
sdk_list_modules
sdk_show_module		 Browse the Platform SDK's module registry — what each buildable module contains and depends on.
sdk_plan
sdk_validate		 Order modules into a dependency-correct build plan, and check a built tree against the manifest.

The same screen sets the research defaults a call gets when your agent doesn't say — time budget, whether to search the web, which model — and whether the agent may override them at all. Locking the budget is the blunt cap on what a single call can cost.

Exposure lives on your account, not in the key. Narrow it and every key you have issued is narrowed on its next call, with nothing to re-issue. A key holder can see the effects; they can never change them.

What crosses the wire

Be clear-eyed about this, because it is the opposite of the Se/cure tier's promise: an MCP call is a Se/rver call. The question you send reaches this server, goes upstream to the model and the search provider, and is recorded in the same full-visibility interaction log every chat is. The answer comes back over the same connection.

If a research question must never rest on a server, it does not belong on this endpoint — DeepResearch.Se/cure is the tier where the server is in no data path at all.

If it won't connect

  • 401 with a JSON-RPC error — the key is expired, revoked, or the MCP server is switched off for your account. Settings → MCP server says which; mint a new key if in doubt.
  • A sign-in page instead of JSON — no key reached the server. The header must be exactly Authorization: Bearer <key>; check your client didn't drop or rename it.
  • No tools listed — everything is switched off, or the master switch is. Same screen.
  • A tool call says "Unknown tool" — that tool is not exposed. Clients cache tool lists; reconnect after switching one on.
  • "Research quota exceeded" — MCP calls share your account's quota with the chat. It says when it resets.
