What this project is for

DeepResearch.se is innovation and research on the privacy capabilities of LLM applications: how far a real, useful research assistant can be pushed toward provable privacy, and where that trades against capability. Stated more precisely, it is a deep-research security architecture — how research is distributed outward to people and machines the originator doesn't control, how insight is aggregated back, and what every hop actually exposes, written down instead of assumed.

The proof is the site itself, in two tiers. DeepResearch.Se/cure runs the research entirely in your browser, on your own API key, with the server absent from every data path. DeepResearch.Se/rver is the signed-in tier, where a server buys capability and protects what it handles with encryption and policy. It's still experimental and nowhere near production-ready. It began as a weekend build through the Claude Code iPhone app, kept in the build story.

The architecture, in short

One question, two data paths. A research run is the same five deterministic phases either way — triage → search → gap check → synthesis → validation — with no function calling anywhere in the pipeline, so it works on any model in the catalog. What differs is where those phases execute, and therefore what anyone but you can see.

The full version — the serving chain, privacy and capabilities compared side by side, workspaces, and the Linux VM that boots inside the tab — is the architecture story.

Some of what it does

  • Deep research with citations — it plans its own web searches, checks that they cover the question, and answers with numbered sources inside a time budget you set.
  • Workspaces that travel — a named collection of chats and material. In Se/cure the share link is the workspace: it carries the content, with no record on any server.
  • A real Linux in the browser tab — a WebAssembly VM the agent runs and tests code in, streaming only the disk blocks it reads.
  • Open model catalog — beyond Berget, Claude and GPT, it runs Hugging Face models. The Models agent browses that open catalog, shows what each one costs before you commit, and enabling one puts it in every agent's model menu. In Se/cure the same models run on your own key, called straight from the browser.
  • Introspection — ask the site how it works and it answers from its own deployed source, committed alongside it.
  • Agent Studio — distils this site into a new agent, or into a whole new platform, and publishes it live at its own URL.
  • Orchestrator — decomposes one request into a team of sub-agents the Worker runs in parallel waves, drawn as a live graph.
  • Usable as a tool — the site is itself an MCP server, so Claude, Cursor or any MCP client can call its deep research.
  • Open interchange standards — workspace bundles (DRSW/1) and the pipeline itself (DRPL/1) are written as standards a second implementation could follow, with this site as the reference one.
  • Integrations as extensions — maps and street view, host intelligence, model-hub search: examples behind one registry seam, never wired into the core.
  • Swedish and English — every deterministic intent gate takes both, with parity tests to keep it that way.

Open source, MIT

All of it is on GitHub under the MIT licence — the Worker, both clients, the tests, the documentation. It's an 80 % project exploring capabilities rather than a product being shipped, and the repository is what makes the claims on this page checkable: the site is deployed straight from it, so what you read is what production serves. Take it and reuse it.

DeepResearch.se

A deep-research AI assistant that plans its own web searches, checks they cover the question, and answers with numbered citations — and an open experiment in how private an AI assistant can be made.

It does

  • Research a question properly: its own searches, cited answers, within a time budget you set.
  • Read what you attach, run code in a Linux sandbox that boots in this tab, and explain its own source.
  • Run entirely in your browser on your own API key — no account, no cost to anyone.

It doesn't

  • Sell anything — no ads, no trackers, not a commercial product.
  • See your chats in DeepResearch.Se/cure: the server isn't in the data path, by construction.
  • Take open signups — the hosted tier is approval-gated.
