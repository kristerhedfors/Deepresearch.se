lypning — measured

A mixture of Pythons: a Rust subset, a MicroPython variant and CPython, with a classifier that picks per program. This page shows two different kinds of number and never mixes them — what your own browser's Linux VM measures right now, and what the project has published about itself, commit by commit.

Live measured here

The battery runs inside the x86 Linux VM in this tab — the same sandbox the research agents run code in, and the environment lypning exists for. Each case is its own short command, because a command that crosses the VM's exec ceiling does not fail, it destroys the VM. min of N, not mean: noise in a browser tab only ever adds time, so the minimum is the least biased estimate. Every row but startup is floor-subtracted.
