The two research corpora

Searched by meaning rather than keyword. Both hold abstracts only — no full text — so a question answered only in a paper's methods section cannot be answered from these corpora at all.

These corpora are shaped, not complete. A search that finds nothing may mean the paper is outside what was ingested, or that the query missed it — those look identical from the outside. Telling them apart is the last section.
Which assistant reaches them. Both corpora belong to Deep Science, the agent that answers only from the peer-reviewed literature; the PubMed side is shared with the Palaeogenomics agent, whose only literature source it is. No other chat mode searches either one. Both stay open to the site's MCP server, which has no notion of an agent — that is how an outside client, and the accuracy batteries, reach them.

Subjects filled deliberately

On top of the bulk sweeps, these were filled by name — every paper found for the topic, regardless of date — because the bulk windows alone left them unusable. Each has a published set of questions whose answers are verified present in the corpus.

Is it missing, or just not found?

Different problems, different fixes, and indistinguishable from a search result alone. Check membership by id first — if the paper is in the index the problem is the query; if it is not, no rephrasing will ever find it.

Present but not retrieved

  • The query paraphrases the title rather than the paper's contribution. Retrieval over abstracts rewards the second.
  • The answer sits in the truncated part of the abstract — 88% of PubMed records are stored cut.
  • The subject is crowded. Retrieval difficulty is a property of the neighbourhood, not the question: the same domain scores 100% recall@10 on arXiv and 73% on PubMed, purely because its vocabulary is distinctive in one corpus and ordinary in the other.
  • The query is in vernacular Swedish. Cross-lingual ordering holds, but absolute scores collapse by one to three orders of magnitude, so a correct match can fall below a relevance floor tuned on English.

Genuinely absent

It can be ingested by name — both corpora have a named-list path — but that is a corpus change and should be followed by a retrieval measurement rather than assumed to have helped. One kind of miss is permanent: a record whose abstract is empty has nothing to embed and is unreachable at any threshold.

How these numbers stay true

MEASURED figures are read from the live index when this dataset is built, and carry that timestamp. RECORDED figures describe a fill that already happened — what a harvest read, what it dropped — which cannot be re-derived from the index afterwards, and carry the date they were measured on instead.

The page is generated rather than hand-written because the equivalent claim inside the code went stale exactly once and did real damage: an internal note told the research agents that nothing before October 2023 was in the arXiv index, while tens of thousands of papers sat below that line. A page maintained by hand drifts the same way, where readers rather than agents would meet it.
